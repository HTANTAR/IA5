    Sin conectar
    ¿El servidor no tiene red? No hace falta conectar: completá los datos abajo y usá Comandos para consola.

    2 Configurar IP fija

    Recomendado. Desactivalo solo si esta PC no va a poder llegar a la IP nueva (otra VLAN / red).

      2 Acceso por grupos de seguridad de AD

      Conectá el servidor para ver si está unido al dominio y qué grupos tienen acceso.

      Dar acceso a un grupo

      Unir el servidor al dominio (si todavía no lo está)
      Plantilla de users.deny

      Se escribe en el servidor al unirlo. Para copiarla de un servidor que ya funciona: conectate a ese servidor y en el estado de AD apretá "Usar su users.deny como plantilla". Se guarda solo en esta PC.

      Unir el servidor crea su cuenta de equipo en AD y le permite consultar usuarios y grupos; por sí solo no da acceso a nadie. Al terminar se habilitan automáticamente los grupos que cargaste arriba. Requisitos: DNS del servidor apuntando a los controladores de dominio, hora sincronizada y un usuario con permiso para crear equipos en la OU.

      2 Comandos para ejecutar en la consola del servidor

      Para servidores sin red (o cuando preferís hacerlo a mano desde la consola de VMware/Hyper-V/iLO/iDRAC). Usa los datos cargados en las pestañas IP fija y Acceso por grupos AD.
